# Pug + Less + JavaScript

Production-ready webpack starter template using:

- Pug
- Less
- Modern JavaScript
- Webpack 5
- @razerspine/pug-ui-kit

---

## 🚀 Getting Started

```bash
npm install
npm run dev
npm run build
npm run preview
```

---

## 🎨 UI System — pug-ui-kit

Integrated modular UI system.

Main style file:

```
assets/styles/main.less
```

```less
@import "@razerspine/pug-ui-kit/less/ui-kit";
```

Supports:

- Themes
- Modular components
- Layout utilities
- Pug mixins
